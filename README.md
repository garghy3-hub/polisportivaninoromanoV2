# Polisportiva Nino Romano Milazzo — V2

Nuova versione del sito ufficiale della Polisportiva Nino Romano Milazzo.

## Stack previsto

- React
- TanStack Start
- TypeScript
- Tailwind CSS v4
- Cloudflare Workers (SSR / deployment target)
- Supabase (backend e dati, da ispezionare prima di modifiche)

## Principi di sviluppo

- La V1 resta separata e non va modificata.
- Non inventare risultati, classifiche, calendario, roster o statistiche.
- Non inserire credenziali, token o segreti nel codice.
- Ispezionare lo schema Supabase prima di qualsiasi intervento sul database.
- Nessun deploy senza autorizzazione esplicita.
- Netlify non è il target di deployment.

## Stato

Repository iniziale: scaffold da creare. Prima fase: configurazione e struttura applicativa, senza modifiche al database o deploy.
